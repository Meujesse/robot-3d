# Robot 3D — viewer pour Genially

Petit robot volant en 3D interactive (rotation automatique, manipulation à la souris, ombre au sol, fond transparent).

- `index.html` : page viewer (Google model-viewer)
- `robot.glb` : modèle optimisé pour le web (1,2 Mo)
- `robot-source.png` : image d'origine (ChatGPT), convertie en 3D avec Tripo

Réglages par l'URL : `?speed=30` (vitesse de rotation), `&float=0` (sans oscillation), `&shadow=0` (sans ombre), `&rotate=0` (sans rotation auto).
